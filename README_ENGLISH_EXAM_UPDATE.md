# Moon Exam · 영어 시험 만들기 (이전 수정 누적)

## 이번 추가
- MoonWords 하단 `영어 시험 만들기` → 별도 `exam.html` 화면. Printmaker와 별개 서비스이며 MoonWords의 현재 로그인으로 본문을 읽습니다.
- 저장된 본문 1~5개 검색·선택 (통합단어장 제외).
- 유형별 0~5문제, 전체 최대 12문제. 개수는 선택한 본문 전체에 배분.
- 첫 글자 + 영영풀이 빈칸, 제시 단어 2개 + 조건 영작, 밑줄 단어의 영영풀이 4지선다, 문법 가이드 + 대화 빈칸.
- 저장된 필기와 직접 입력한 수업 조건 참고. 조건이 없으면 본문 기반 문법 조건임을 표시.
- 각 문제에 출처 본문 표시, 문제/지문/보기/정답/해설 수정.
- 문제지와 정답·해설지 각각 인쇄 또는 브라우저의 PDF 저장. 시험은 현재 화면에서 편집하며 새로고침하면 초기화되므로 인쇄/PDF로 보관하세요.
- 서버에서 본문 소유권, 생성 개수와 필수 필드, 본문 인용 근거, 같은 유형의 동일 문제 중복 검증.
- AI 생성 품질은 자료에 따라 다르므로 최종 사용 전에 확인하세요. 서술형은 모범답안입니다.

## 네가 할 일 (이 순서로 한 번)
1. ZIP 압축을 풉니다. 기존 저장소를 지우지 말고 같은 경로에 새 파일을 추가하고 기존 파일을 덮어씁니다.
2. 이전 누적 수정의 SQL을 아직 실행하지 않았다면 Supabase → SQL Editor에서 `supabase/APPLY_20261020_UPDATE.sql` 전체를 실행합니다. 이미 실행했으면 생략합니다. 이번 시험 기능 자체는 추가 테이블이 필요 없습니다.
3. Supabase → Edge Functions → `process-document`에서 ZIP의 `supabase/functions/process-document/index.ts` 전체로 교체하고 Deploy합니다. 기존 GEMINI_API_KEY 등 Secrets는 유지합니다.
4. GitHub에 변경 파일을 모두 Commit/Push합니다. `exam.html`, `src/features/exam/` 폴더, `vite.pages.config.ts`도 반드시 포함합니다.
5. GitHub Actions 배포 완료 후 MoonWords를 새로고침하고 하단의 `영어 시험 만들기`로 들어갑니다. 직접 주소는 https://seouk-moon.github.io/moonwords/exam.html 입니다.
6. 본문과 유형을 고르고 생성한 뒤 문제를 검토·수정합니다. `문제지 보기`에서 인쇄하고, `정답·해설 보기`에서도 별도로 인쇄합니다.

기존 로그인 설정/VITE_SUPABASE_URL/VITE_SUPABASE_PUBLISHABLE_KEY를 그대로 사용합니다. 새 API 키를 프런트엔드에 넣지 않습니다.

## 함께 들어 있는 이전 수정
폴더 먼저 선택, 상단 뒤로가기 제거, 반복 캐릭터 반응, 통합단어장에 추가 단어 선택 반영, 사진 영역 선택 후 본문 생성, 생성 중 단어 4지선다 및 정오답 기록, 첫 파일 필수/두 번째 선택과 파일별 원문·필기본 지정, PDF/짧은 필기 처리. 상세는 README_UPLOAD_FLOW_UPDATE.md 참조.

## 검증 범위
Pages 빌드, 서버 입력·권한·생성 결과 검증 테스트, 기존 사진 분석/학습 기록 회귀 테스트. 브라우저에서 API 응답 모의 데이터로 본문 선택, 4개 유형 표시, 편집, 정답 분리, 인쇄 CSS와 360/390/768px 화면을 검증했습니다. 운영 계정의 실제 AI 호출과 배포는 수행하지 않았습니다.
