# 원문 + 필기본 수업 맞춤 출제


이전 자동 본문 생성 업데이트(4c4c7be)를 반영한 상태에서 아래 기능을 추가하는 변경 파일 묶음입니다. 기존 기능은 유지합니다.

- 파일 올리기에서 원문과 필기본을 별도로 선택합니다. 원문만 / 필기본만 / 둘 다 가능합니다.
- 원문은 PDF·DOCX·TXT·MD, 필기본은 같은 형식 및 JPG·PNG·WEBP를 지원합니다.
- 사진 촬영과 필기를 함께 사용하려면 필기본과 조건을 먼저 선택한 뒤 촬영하세요.
- 필기 PDF는 8쪽·20MB까지 페이지 이미지와 텍스트를 함께 분석합니다. 더 긴 파일은 나눠 올려 주세요. DOCX는 텍스트만 읽으므로 손글씨나 도형은 PDF 또는 사진으로 올려 주세요.
- 필기본만 있을 때 실제 영어 지문이 읽히지 않으면 원문/선명한 사진을 요청합니다. 없는 본문을 만들지 않도록 지시합니다.
- '수업에서 배운 조건'에 5형식, 목적격 보어 등 실제 수업 조건을 보충할 수 있습니다.
- '영영풀이 빈칸 + 조건 영작 문제 만들기'가 기본 선택됩니다. 해제하면 기존 학습지만 생성합니다.
- 새 본문 상단의 '수업 맞춤 문제'를 펼쳐 풉니다. 각 유형 최대 5개를 요청하며 근거 부족/잘못된 문항 제거에 따라 실제 수가 줄어들 수 있습니다.
- 빈칸: 실제 본문 문맥 + 첫 글자 + 영영풀이. 첫 글자를 포함한 단어 전체를 입력합니다. 대소문자와 양끝 공백은 무시하고 채점합니다.
- 영작: 한국어 해석 + 제시어 2개 + 수업 조건. 예시 답안과 해설을 보고 직접 확인합니다. AI 자동 채점은 하지 않습니다.
- 필기/본문 출제 근거를 답안 확인 후 볼 수 있습니다. 판독이 잘못되거나 조건을 어긴 AI 답안이 있을 수 있으므로 실제 수업 내용과 비교하세요.
- 생성한 문제와 필기 추출 텍스트/파일명/추가 조건은 기존 documents.analysis에 저장됩니다. 필기 원본 파일·이미지는 별도 저장하지 않습니다. 영어 답안 입력과 자가 확인 상태는 이번 화면에서만 유지됩니다.
- 기존 본문은 자동으로 바뀌지 않습니다. 이 기능은 새 본문 생성에 적용됩니다.

### 내가 할 일 (순서대로)
1. moonwords-class-exercises-update.zip을 내려받아 압축을 풉니다.
2. MoonWords 저장소 폴더에 ZIP의 폴더 구조대로 합치고 같은 이름 파일만 덮어씁니다. 다른 기존 파일은 지우지 않습니다.
3. GitHub Desktop에서 변경을 Commit 하고 Push origin 합니다.
4. Supabase → Edge Functions → process-document → Code를 엽니다.
5. ZIP의 supabase/functions/process-document/index.ts 전체 내용을 복사해 기존 코드를 교체합니다.
6. Deploy updates를 누릅니다. SQL, 키, 패키지 변경은 없습니다.
7. GitHub Pages 배포 완료 후 새로고침 → 새 본문 → 파일 올리기에서 원문/필기본을 선택해 생성합니다.
8. 새 본문 상단의 수업 맞춤 문제에서 빈칸과 영작을 확인합니다.

검증: 자동 테스트 12개, Pages 빌드 통과. 모의 서버를 이용한 브라우저 검사에서 필기본만 업로드, 원문+필기 PDF 업로드, 실제 PDF 이미지 렌더링, 저장, 두 문제 유형 답 확인, 모바일 360/390/768px 레이아웃을 확인했습니다. 실제 Gemini 호출 및 Supabase 배포는 수행하지 않았습니다. 전체 TypeScript 검사에는 기존 mammoth 선언 오류 등 저장소의 기존 오류가 남아 있으며 추가한 src 코드 오류는 없습니다.
