# MoonWords 로그인 기기 관리 업데이트

기준: GitHub main 9040e3e (2026-10-18 확인). 이전까지 반영 완료한 기능을 유지하며, 이번 묶음은 로그인 기기 관리 변경만 포함합니다.

## 이번 수정
- 프로필에 로그인된 기기 목록, 로그인 시각, 최근 활동 시각, 현재 접속 표시 추가.
- 특정 로그인만 해제하는 버튼 추가. 기존 모든 기기 로그아웃 버튼 유지.
- 접속 중인 앱은 약 60초마다, 다시 포커스를 얻을 때도 실제 서버 세션을 확인.
- 원격 해제된 세션은 로그인 화면으로 이동하며 저장된 로그인 정보 정리.
- 계정 전환/로그아웃 시 이전 본문·폴더·단어·학습 통계를 초기화하고, 이전 계정의 늦은 조회 결과가 덮어쓰지 못하도록 처리.
- 브라우저별 자동로그인과 공유 URL 인증 정보 차단 설정 유지.

## 적용 순서
1. GitHub Desktop에서 저장소를 최신 상태로 받습니다. ZIP 안의 src, supabase, tests 폴더를 저장소 루트에 합쳐 넣습니다. 기존 폴더를 삭제하지 말고, 같은 이름의 파일만 덮어씁니다. README_DEVICE_SESSIONS.md는 안내 파일입니다.
2. Supabase에서 MoonWords 프로젝트 → SQL Editor → New query를 엽니다.
3. supabase/migrations/202610180001_device_sessions.sql 전체를 붙여 넣고 Run을 누릅니다. 성공하면 SQL 설정은 끝입니다. 같은 SQL을 다시 실행해도 됩니다.
4. GitHub Desktop에서 변경 파일을 Commit → Push 합니다. GitHub Actions의 Pages 배포가 성공하면 사이트를 새로고침합니다. Edge Function 배포나 새 API 키 발급은 필요 없습니다.
5. 로그인 → 내 프로필 → 로그인된 기기에서 확인합니다. PC와 휴대폰 등 서로 다른 브라우저 두 곳으로 로그인해서 시험하세요.

SQL 미적용 상태에서도 기존 로그인은 유지되지만, 기기 목록에는 SQL 적용 안내가 표시됩니다.

## 확인 방법
- PC와 휴대폰에서 각각 로그인: 두 세션이 목록에 표시되고 각각 현재 접속 표시가 달라야 합니다.
- PC에서 휴대폰 세션 로그아웃: PC는 유지되고, 휴대폰은 약 1분 이내 또는 다시 화면을 열 때 로그인 화면으로 이동합니다.
- 이 기기 로그아웃: 다른 기기의 로그인은 유지되어야 합니다.
- 모든 기기 로그아웃: 해당 계정의 전체 세션이 해제되어야 합니다.
- 시크릿 창에서 기본 사이트 주소를 열면 로그인 화면이 표시되어야 합니다. 인증 메일 링크는 공유하지 마세요.

## 표시·반영 범위
- 정확히는 하드웨어 단위가 아니라 로그인 세션 단위입니다. 같은 PC의 서로 다른 브라우저/프로필 또는 탭 전용 로그인은 별도로 표시될 수 있습니다.
- 기기 이름은 브라우저가 제공하는 정보로 만든 참고 표시입니다. 고유한 기기 식별이나 접속 위치 정보는 수집하지 않습니다.
- 기존 세션도 목록에 표시되며, 새 버전으로 앱을 열면 기기 이름과 활동 시각이 등록됩니다. 이전 세션에서 기기 정보가 없으면 ‘이전 로그인 · 기기 정보 없음’으로 표시합니다.
- 접속 확인이 되지 않는 오프라인 상태에서는 원격 해제를 즉시 확인할 수 없습니다. 구버전 화면은 새로고침하거나 인증 갱신 시 반영됩니다.
- 원격 로그아웃은 서버의 세션/갱신 토큰을 삭제합니다. 이미 발급된 접근 JWT는 만료 전까지 기존 데이터 API에서 유효할 수 있습니다. 모든 API를 즉시 차단하는 기능은 아닙니다.
- SQL은 Auth 세션을 읽고, 본인 요청 시 본인 세션과 갱신 토큰만 삭제합니다. 본문/단어장/파일은 삭제하지 않습니다. Supabase 관리 권한으로 실행해야 합니다.
- 기존 ‘모든 기기 로그아웃’은 Supabase 표준 global 로그아웃을 계속 사용합니다.

## 검증
- GitHub Pages 프로덕션 빌드 통과.
- PostgreSQL 호환 환경에서 실제 SQL 실행: 다른 계정 접근 차단, 취소된 세션의 조회/재등록/다른 세션 취소 차단, 갱신 토큰 삭제, 세션별·전체 해제, 익명 접근 차단, 재실행 통과.
- 브라우저에서 테스트용 서버 응답으로 목록·선택 해제·재접속 감지·미설정 오류·390px 모바일·별도 브라우저 분리·URL 토큰 차단 확인.
- 실제 운영 Supabase 프로젝트에는 아직 SQL을 실행하거나 배포하지 않았습니다. 적용 후 두 기기로 최종 확인하세요.
- 전체 TypeScript 검사에는 기존 refactor-backup/Cloudflare/Deno 설정 및 mammoth 타입 선언 오류가 남아 있으며, 변경된 소스에서 새 타입 오류는 확인되지 않았습니다.
