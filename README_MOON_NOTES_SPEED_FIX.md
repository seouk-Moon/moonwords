# 2026-10-21 달 중복 · 필기 출제 범위 · 생성 지연 수정

GitHub main d936773 기준 수정 파일입니다. 기존 본문/단어장/드라이브/시험 기능을 유지합니다.

## 확인한 원인과 수정
1. MoonGrowthCard의 MoonCharacter와 인사말 span이 동일한 key를 사용했습니다. 키를 구분해 반복 클릭 시 SVG나 인사말이 남는 문제를 수정했습니다. 매 클릭 반응은 유지합니다.
2. 기존 시험 생성은 '필기를 참고하고 부족하면 본문 문법 사용'이므로 필기 전용이 아니었습니다. 시험 화면의 출제 범위를 기본 '필기본에 있는 내용만'으로 추가했습니다. '본문 전체 (필기 참고)'도 선택할 수 있습니다. 필기 전용은 모든 선택 본문에 저장된 notesText가 있어야 하며 질문마다 필기의 실제 연속 인용 구절을 evidence로 반환·검증합니다. 정답/해설에서 필기 근거를 볼 수 있습니다. AI의 의미 판단까지 기계적으로 보장할 수 없으므로 최종 검토는 필요합니다.
3. 본문 업로드 시 수업 맞춤 연습문제도 필기가 있으면 필기 표시만 출제하도록 지시하고, 필기 대신 본문 근거로 만든 문제는 제외합니다. 사진 필기는 이미지 인식 상태에 따라 근거가 달라질 수 있습니다.
4. 기존 Gemini 호출에는 개별 응답 제한이 없고, 기본 설정에서 서버는 여러 번 호출하며 업로드 화면에서도 전체를 다시 요청할 수 있었습니다. 응답 본문 수신까지 호출당 최대 45초, 전체 AI 호출 예산 75초, 최대 두 모델로 제한했습니다. Retry-After가 2초보다 길면 즉시 안내합니다. 업로드 화면의 추가 자동 재시도를 없앴습니다. 시험 화면에 경과 초를 표시합니다. 이는 무한 대기/중복 재시도 개선이며 모든 문제가 특정 시간 안에 성공한다는 의미는 아닙니다.

4. MoonWords를 새로고침합니다. PC는 Ctrl+Shift+R. 달을 반복 클릭해 중복이 없는지 확인합니다.
