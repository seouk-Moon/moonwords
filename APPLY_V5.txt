MoonWords v5 적용 순서

1) 이 ZIP의 moonwords-github 폴더 안 파일을 기존 프로젝트 루트에 복사하고 같은 이름은 덮어쓰기.
   - 기존 .git, .env, .env.local은 유지.

2) Supabase Dashboard → SQL Editor → New snippet.
   `SUPABASE_LEARNING_SETUP.sql` 내용을 전부 붙여넣고 Run 1회.
   - 기존 본문/폴더/단어/진행 데이터는 삭제되지 않음.
   - 폴더용 SQL을 이미 실행했다면 다시 실행할 필요 없음.

3) 로컬에서:
   npm ci
   npm run build:pages

4) 앱 새로고침 후 내 학습 화면에서 성장 대시보드 확인.

기록 규칙
- 주간 통계: 매주 월요일 기기 로컬 시간 기준으로 새 주 시작
- streak: 주간 초기화와 무관하게 계속 누적
- streak 인정: 하루 퀴즈 5문제 이상 OR 본문 5문장 이상
- 정답 +10 XP / 오답 +3 XP / 새 학습 문장 +5 XP / 저장 단어 +4 XP / 본문 최초 완료 +50 XP
- 500 XP마다 레벨 상승

참고
- 저장 단어 수와 이미 완료된 본문 수는 기존 DB 상태를 최대한 이어받음.
- 과거 날짜별 퀴즈 정답률/streak/학습시간은 예전 버전에 세부 로그가 없었기 때문에 v5 적용 이후부터 정확히 누적됨.
