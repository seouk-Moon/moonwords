# 2026-10-20 누적 업데이트

기준: GitHub main 26e7bae. 바로 전 폴더 선택/달 반응/통합단어장 선택 추가와 이번 사진·파일 업로드 변경을 모두 포함합니다. 이전 ZIP 대신 이 ZIP 하나를 적용하세요.

## 이번 변경
- 사진 촬영/앨범 선택 → 미리보기에서 원하는 영역을 드래그 또는 숫자로 지정 → ‘선택한 영역으로 본문 만들기’ 순서입니다. 생성 이후 별도 OCR 수정 단계는 없습니다.
- 영역을 확정한 뒤 한국어+영어 OCR 및 사진 AI 분석을 수행하는 동안 전체 화면에서 단어 퀴즈를 풉니다.
- 최근 학습한 본문 8개의 저장한 단어에서 오답률을 우선해 고릅니다. 상단에는 출처 본문, 문제에는 영어 단어만, 보기에는 뜻 4개를 표시합니다. 본문 이해 객관식/예문은 이 대기 퀴즈에서 제외했습니다.
- 답변을 원래 단어에 연결해 학습 이벤트, 누적 정답/오답/복습 횟수, 최근 10회 기록과 ‘오답만 풀기’ 대상에 반영합니다. 정답으로 재도전한 단어는 오답 대상에서 빠집니다. 별표·더 중요·세트 수·메모는 유지합니다.
- 뜻이 서로 다른 보기 4개를 만들 만큼 최근 저장 단어가 없으면 생성 진행 화면을 표시합니다. 모르는 뜻을 임의로 만들어 보기로 쓰지 않습니다.
- 생성이 끝나면 현재 문제가 마지막이라는 안내 후 새 본문으로 이동합니다. 건너뛰기도 유지합니다.
- 파일 업로드는 첫 파일 필수, 두 번째 파일 선택입니다. 파일을 고른 뒤 각각 원문/필기본 종류를 선택해야 생성할 수 있습니다. 원문이나 필기본 중 하나만 올려도 되고, 필기본 먼저/원문 나중도 됩니다. 각 종류 한 파일씩 지원합니다.
- 사진 모드에서는 촬영 사진이 원문이며 별도 필기본을 선택할 수 있습니다. 필기본은 촬영 전 선택해 주세요.

## 본문 생성 오류 관련 수정
- 일반 PDF 파일의 PDF.js worker URL 연결 방식을 수정했습니다. 브라우저에서 ‘Invalid workerSrc type’으로 PDF 읽기가 막히는 경우를 재현하고 수정 후 실제 PDF 읽기를 확인했습니다.
- 별도 원문이 있을 때 짧은 필기(예: ‘5형식’)도 정상 자료로 처리합니다. 원문에는 기존 최소 본문 길이 검사를 유지합니다.
- 사진 OCR이 짧더라도 선택 영역 이미지를 AI가 직접 확인할 수 있도록 전달합니다. 실제 읽을 수 있는 영어 본문이 없으면 빈 문서를 저장하지 않고 안내합니다.
- 필기본만 있는 경우 맞춤 문제 생성 옵션을 꺼도 실제 필기 자료를 분석하도록 수정했습니다.
- AI 결과에 본문이 없는 경우를 검사하고 실패를 안내합니다. AI 분석을 확인한 뒤에 원문 파일 저장을 진행합니다.

실제 배포된 Supabase의 로그·API 키에는 접근하지 않았습니다. 위 수정은 코드와 로컬 검증에서 확인한 문제에 대한 수정이며, 실서버의 별도 모델/한도/인증 오류까지 확인한 것은 아닙니다.

## 내가 할 일 (한 번에 적용)
1. moonwords-folder-collection-update.zip을 다시 내려받아 압축을 풉니다.
2. Supabase → SQL Editor → New query에서 ZIP의 supabase/APPLY_20261020_UPDATE.sql 전체 내용을 붙여넣고 Run 합니다. 직전 통합단어장 SQL을 이미 실행했어도 다시 적용할 수 있습니다. 개별 migration SQL을 또 실행할 필요는 없습니다.
3. ZIP 파일을 MoonWords 저장소 폴더에 구조대로 합치고 같은 이름만 덮어씁니다. 기존 다른 파일은 삭제하지 않습니다.
4. GitHub Desktop에서 Commit → Push origin 합니다.
5. Supabase → Edge Functions → process-document → Code에서 ZIP의 supabase/functions/process-document/index.ts 전체 코드로 교체하고 Deploy updates를 누릅니다.
6. Pages 배포 완료 후 새로고침합니다. 사진은 원하는 영역을 고른 뒤 생성 버튼을 누르고, 파일은 첫 파일과 종류를 선택한 뒤 생성하세요.

새 API 키·모델 설정·패키지 설치는 필요하지 않습니다.

검증: Pages 빌드, 관련 자동 테스트 18개(실제 PostgreSQL에서 원래 단어 정오답/최근 기록/오답 목록 갱신 포함), 실제 한국어·영어 사진 OCR/선택 영역만 인식, 대기 단어 퀴즈와 정오답 요청 1회 기록, 원문 PDF + 짧은 필기, 파일 종류 필수 선택, 모바일 360/390/768px 화면을 확인했습니다. 기존 mammoth 모듈 타입 선언 오류 등 전체 저장소 TypeScript 검사에 남아 있는 기존 오류 외에 추가한 src 오류는 없습니다.
