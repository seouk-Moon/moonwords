# MoonWords v4 revision — 2026-08-23

## Requested changes

1. Removed the duplicate in-page `본문 학습 / 단어장 / 퀴즈` navigation from StudyView. The sticky global header remains the single document navigation.
2. Expanded the quiz completion screen with:
   - 오답만 풀기 (본문 이해 오답이 있을 때)
   - 전체 섞어서 풀기
   - 오답 확인하기 (이번 실행의 틀린 답/정답/설명)
   - 처음으로 (퀴즈 초기 설정 화면)
3. Replaced separate ordering labels such as `앞 문장 / 다음 문장` with one continuous source-style excerpt. The tested section is rendered as `________`, including omitted pieces of a long current sentence around the blank.
4. Wordbook correct/incorrect display now uses a rolling maximum of the most recent 10 word-quiz answer events. The history is stored in existing `study_progress.sentence_notes`, so no new Supabase migration is required. Existing lifetime counters remain only for backwards compatibility.
5. Applied the selected Primary MoonWords logo direction: navy icon, yellow crescent moon, open book, stars, horizontal MoonWords wordmark. Updated favicon to the same icon.

## Existing-history note

Older `correct_count / incorrect_count` totals do not preserve answer order, so they cannot truthfully reconstruct the historical last 10 attempts. The rolling recent-10 history begins accumulating after this v4 update. Until a word receives a new quiz result, the wordbook shows `최근 퀴즈 기록 없음` for that rolling metric.

## Supabase

No new SQL migration is required for v4. The v3 folder migration remains unchanged.
The `process-document` Edge Function was not modified.
