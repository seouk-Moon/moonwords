# MoonWords — 매일 자라는 달 + 사진으로 본문 추가

기준: GitHub main 790a815. 기존 로그인 기기 관리까지 반영된 코드를 기준으로 한 새 변경 묶음입니다.

## 이번 코드에 포함한 수정

### 매일 조금씩 차오르는 달
- 내 본문 첫 화면과 프로필 상단에 달 성장 카드 배치.
- 하루 미션 완료일마다 누적 성장합니다. 1·3·7·14·21일은 이름이 바뀌는 이정표이며, 그 사이 날짜에도 밝은 부분이 매일 조금씩 증가합니다. 21일이면 보름달이 됩니다.
- 오늘 미션을 진행하는 중에도 부분 진행률만큼 미리 차오르고, 완료하면 누적 미션 일수에 포함됩니다. 같은 날 여러 번 공부해도 하루로 셉니다.
- 하루 쉬어도 누적 미션 일수로 키운 달은 줄지 않습니다. 연속 학습 일수는 기존 기준에 따라 별도로 계산합니다.
- 둥실 떠 있기, 눈 깜빡임, 별빛, 궤도, 달을 누르면 인사하기, 하루 미션 완료 축하 알림 추가.
- 프로필에서 이번 주 7일 완료 기록과 현재·최고 연속 일수를 함께 표시. 화면 상단에도 연속 일수 버튼 추가.
- 휴대폰의 ‘동작 줄이기’ 설정을 존중합니다. 효과음은 없습니다.
- 기존 전체 듣기·플래시카드·퀴즈의 하루 목표를 그대로 사용합니다. 프로필의 ‘목표 설정’에서 변경할 수 있습니다. 기존 로직과 같이 목표를 바꾸면 과거 기록도 변경한 목표 기준으로 다시 계산됩니다.
- 자정을 지나거나 다시 화면으로 돌아오면 날짜 기준을 갱신합니다. 날짜는 브라우저 현지 날짜를 사용합니다.
- 많은 퀴즈 기록이 있어도 최근 기록이 잘리지 않도록 학습 기록을 페이지별로 모두 불러옵니다.

### 사진 찍어 본문 추가
- 내 본문에 ‘사진으로 추가’ 바로가기 추가.
- 새 본문 화면에서 ‘사진으로 추가’ → ‘사진 찍어 추가’ 또는 ‘앨범에서 선택’.
- 촬영을 지원하는 휴대폰은 카메라를 요청하고, PC나 지원하지 않는 브라우저는 파일 선택창을 사용할 수 있습니다.
- 미리보기에서 영어 지문 부분을 드래그로 선택하거나 % 입력으로 조절할 수 있습니다. 문제 번호·선택지·다른 단의 글은 제외해 주세요.
- ‘선택한 영역 글자 인식’ → 인식된 영어 본문 확인·수정 → ‘AI 학습지 만들기’로 기존 본문/단어장/퀴즈와 같은 방식으로 저장합니다.
- 영어 인식에는 기존 설치된 Tesseract.js를 사용합니다. 사진 자체는 서버에 업로드하지 않고 기기에서 처리합니다. 인식 엔진·영어 데이터의 최초 다운로드와 이후 기존 Gemini 분석에는 인터넷 연결이 필요합니다.
- 사진 OCR 때문에 유료 AI 요청이 추가되지는 않습니다. 확인한 텍스트를 학습지로 만드는 단계는 기존 AI 요청을 그대로 사용합니다.
- 사진 대신 텍스트만 저장하므로 원본 사진이 MoonDrive나 source-files 공간을 차지하지 않습니다. 원본 사진을 보관하려면 직접 보관해 주세요.
- 최소 40자·최대 120,000자 본문, 사진 파일 최대 20MB. HEIC 등 브라우저에서 읽지 못하는 형식은 JPG·PNG로 다시 선택하세요.
- OCR 취소, 오류 안내, 이미지 크기 조정, 미리보기 주소와 인식 작업 정리 포함.

## 적용 방법
1. ZIP 압축을 풉니다.
2. src 폴더와 tests 폴더를 현재 MoonWords 저장소 루트에 합쳐 넣고 같은 파일만 덮어씁니다. 기존 폴더를 삭제하거나 저장소 전체를 교체하지 마세요.
3. GitHub Desktop에서 변경 내용을 확인하고 Commit → Push 합니다.
4. GitHub Actions의 Pages 배포 완료 후 새로고침합니다. PC에서는 Ctrl+Shift+R을 사용할 수 있습니다.

이번 변경은 추가 SQL 실행, API 키 변경, Supabase Edge Function 재배포가 필요 없습니다. 기존 학습 기록 테이블과 AI 분석 기능을 사용합니다. 기록 저장 오류가 있으면 성장 카드에 안내가 표시됩니다.

## 사용 확인
- 내 본문 첫 화면에서 달과 현재 연속 일수를 확인합니다.
- 달을 누르면 인사 모션이 나옵니다.
- 성장 기록 → 목표 설정에서 원하는 하루 목표를 지정합니다.
- 미션을 모두 마치면 축하 알림이 나오고, 같은 날 재접속만으로 알림이 반복되지는 않습니다.
- 휴대폰에서 ‘사진으로 추가’ → 촬영/앨범 → 지문 영역 → 글자 인식 → 본문 수정 → AI 학습지 만들기 순서로 사용합니다.
- 촬영은 지문이 평평하고 밝게, 글자가 크게 나오도록 해주세요. OCR은 오인식할 수 있으므로 저장 전 확인이 필요합니다.

## 검증과 한계
- Pages 프로덕션 빌드와 신규 기능·기존 세트/출처 관련 16개 테스트 통과.
- 브라우저에서 실제 Tesseract 엔진과 테스트용 영어 이미지로 인식 및 결과 수정 흐름 확인.
- 날짜 중복 계산·연속 학습 중단과 재시작·매일 밝기 증가·진행률·긴 기록 페이지 조회·사진 형식/크기/영역 검사 통과.
- 390px 모바일 화면, 연속 기록, 달 인사, 미션 완료 알림, 동작 줄이기 설정 확인.
- 실제 휴대폰 카메라 하드웨어와 운영 Supabase/유료 AI 호출은 실행하지 않았습니다. 적용 후 본인 휴대폰에서 촬영과 최종 저장을 한 번 확인하세요.
- 전체 TypeScript 검사에는 저장소의 기존 백업/Cloudflare/Deno 설정 오류 및 mammoth 타입 선언 오류가 남아 있습니다. 변경된 소스의 새 타입 오류는 확인되지 않았습니다.
- GitHub와 운영 사이트에는 아직 이 변경을 Push/배포하지 않았습니다.
