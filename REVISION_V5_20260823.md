## New learning growth system
- Every quiz answer is logged by quiz mode and correctness.
- Every newly understood sentence is logged as study activity.
- Saved vocabulary and first full-document completion award activity/XP.
- Learning time is tracked in study / vocabulary / quiz views.
- Quiz sessions are recorded into the existing `quiz_attempts` table.

### Weekly system
- Weekly stats are calculated Monday 00:00 → Sunday 23:59 using browser local time.
- Weekly values start fresh automatically without deleting history.
- Current streak, total XP, level, achievements and personal records do NOT reset weekly.

### Streak qualification
A date qualifies if either:
- 5+ quiz answers, OR
- 5+ unique studied sentences.

If today's threshold has not yet been reached, yesterday's active streak remains visible until the day is over.

### Moon streak stages
- 0 days: new start 🌑
- 1–2: thin crescent 🌒
- 3–6: crescent 🌙
- 7–13: half moon 🌓
- 14–20: waxing moon 🌔
- 21+: full moon 🌕

### XP
- Correct quiz answer: +10 XP
- Incorrect quiz answer: +3 XP
- Newly studied sentence: +5 XP
- Saved word: +4 XP
- First completion of a document: +50 XP
- Level up every 500 total XP

### Dashboard
- streak + moon growth

- weekly calendar

- comparison with previous week
- quiz-mode accuracy
- 7-day activity chart
- achievements
- personal records
- recent dated learning history
- lifetime summary

## Database
Run `SUPABASE_LEARNING_SETUP.sql` once in Supabase SQL Editor.
It creates only:
- `learning_events`
- `learning_sessions`

No existing documents, folders, vocabulary or progress rows are deleted.
The existing `quiz_attempts` table is reused.
